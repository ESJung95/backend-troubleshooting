# backend-troubleshooting

> 문제를 마주하고 해결 과정을 포스트모템 형식으로 기록하는 백엔드 트러블슈팅 노트입니다.

## 저장소 설명

문제를 해결하며 배운 것들이 시간이 지나 흐려지는 게 싫어서, 해결 과정을 문서로 남기기 시작했습니다. <br>
개인 노션에 쌓아온 기록 중 공유할 만한 것들을 옮겨둡니다.

기록할 때 지키려는 것들입니다.

1. **실패한 시도까지 남깁니다.** 
<br> 잘못 짚은 가설과 상황을 악화시킨 조치도 기록합니다. 다음에 같은 실수를 반복하지 않기 위해서입니다.

2. **근본 원인까지 추적합니다.** 
<br> 해결됐다는 사실보다, 왜 해결됐는지를 설명할 수 있는 상태를 목표로 합니다.

3. **재발 방지로 마무리합니다.** 
<br> 같은 문제를 다시 만나지 않도록 무엇을 바꿨는지까지 남깁니다.
